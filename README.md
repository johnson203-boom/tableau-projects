#### Tableau Data Visualizations 

A collection of interactive dashboards, exploratory analyses, and business intelligence reports built in Tableau. 

#### Overview

Each project in this repository transforms raw data into intuitive visual stories, applying: 

* **Dynamic Interactivity:** Parameters, filter actions, and responsive layouts.
* **Custom Logic:** LOD expressions, table calculations, and tailored metrics.
* **Data Preparation:** Cleaned and structured datasets via SQL, Excel, and Tableau Prep.
